# Дашборд аналитики продаж и удержания клиентов (Power BI)

Интерактивный дашборд в Power BI для анализа unit-экономики, динамики продаж и поведения клиентов на основе датасета SuperStore.

## 📊 Ключевые разделы дашборда
* **Обзор (Overview):** Выручка (Total Sales), Прибыль (Total Profit), Маржинальность (Profit Margin) и Средний чек (AOV).
* **Анализ продаж:** Динамика выручки по месяцам с возможностью детализации (Drill-down) до категорий товаров.
* **Фильтрация:** Интерактивные срезы по Годам и Регионам для мгновенного пересчета метрик.

## 🛠 Технический стек & Инструменты
* **Power Query:** Очистка данных, изменение текстовых форматов дат на `Date`, удаление дубликатов, создание календарных столбцов (Год, Месяц).
* **DAX (Data Analysis Expressions):** Написание кастомных мер с использованием безопасного деления `DIVIDE` и уникального подсчета `DISTINCTCOUNT`.
* **Моделирование:** Связывание таблиц по схеме "Звезда" (Star Schema).

## 🚀 Как запустить проект
1. Скачайте файл `Sales_and_Retention_Dashboard.pbix` из этого репозитория.
2. Откройте его через бесплатную программу **Power BI Desktop**.
